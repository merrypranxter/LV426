# Assets Directory

This folder is reserved for images, diagrams, and visual reference materials related to the Alien franchise database.

## Intended Contents

- **Xenomorph lifecycle diagrams** — visual representation of egg → facehugger → chestburster → adult
- **Ship schematics** — Nostromo deck plans, Sulaco layout, Prometheus cross-sections
- **Timeline graphics** — visual in-universe chronology
- **Character portrait references** — stills and promotional images (rights-cleared only)
- **Location maps** — LV-426, LV-223, Engineer installations
- **Corporate org charts** — Weyland Corp → Weyland-Yutani hierarchy

## File Format Guidelines

- Images: `.png` or `.jpg`
- Diagrams: `.svg` preferred for scalability
- Naming convention: `[category]-[subject]-[descriptor].[ext]`
  - Example: `xenomorph-lifecycle-full.svg`
  - Example: `ship-nostromo-deckplan.png`
  - Example: `location-lv426-overview.jpg`

All assets in this directory should be original creations, public domain, or properly licensed. Do not include copyrighted Twentieth Century Studios / Disney materials without authorization.
